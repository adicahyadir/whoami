## 👋 Tentang Saya

Halo! Saya **Adi Cahyadi Ramadhan** (dikenal secara online sebagai **EnigmaAura** / `@adicahyadir`).

Saya berfokus pada pengembangan antarmuka web modern yang cepat, responsif, dan mudah digunakan. Berbekal pengalaman di bidang **Frontend Engineering**, **UI/UX Design**, serta **IT Support**, saya menyatukan estetika desain, performa teknis, dan pengalaman pengguna yang optimal.

- 🔭 **Sedang Membangun**: Aplikasi web modern dan terukur menggunakan **Next.js**, **React**, serta arsitektur CSS terkini.
- 🌱 **Sedang Dipelajari**: **Aplikasi Terdesentralisasi Web3 (dApps)**, **Integrasi AI** (LLM API & Agents), serta optimasi performa web tingkat lanjut.
- ✍️ **Menulis & Mempublikasi**: Dokumentasi teknis, panduan pengembang di **GitBook**, dan artikel tutorial di **Medium**.
- 💬 **Diskusi Terbuka**: Pengembangan frontend web, arsitektur komponen UI, prototyping Figma, pemecahan masalah IT (troubleshooting), dan performa aplikasi web.
