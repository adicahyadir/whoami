## 👋 About Me

Hi there! I'm **Adi Cahyadi Ramadhan** (also known online as **EnigmaAura** / `@adicahyadir`). 

I specialize in crafting high-performance, accessible, and visually captivating modern web interfaces. With a strong background spanning **Frontend Engineering**, **UI/UX Design**, and **IT Support**, I bridge the gap between design aesthetic, technical execution, and user experience.

- 🔭 **Currently Building**: Scalable web applications with **Next.js**, **React**, and modern CSS architecture.
- 🌱 **Actively Exploring**: **Web3 dApps**, **AI Integration** (LLM API & Agents), and Next-Gen Web performance.
- ✍️ **Writing & Publishing**: Technical documentation, developer guides on **GitBook**, and articles on **Medium**.
- 💬 **Ask Me About**: Frontend web development, component architecture, Figma prototyping, IT troubleshooting, and web performance.
